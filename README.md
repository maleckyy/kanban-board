# Kanban & Todo Board

A simple app to organize your daily tasks and manage your time better. It combines a Kanban-style board and a daily todo list.


## Features

- Kanban board for tasks
- Daily todo list
- Easy task management and time tracking


## Technologies

- Vite
- React
- TypeScript
- Zustand
- React Hook Form
- Zod
- Tailwind CSS
- React Aria Components
- Styled Components
- PWA


## Testing

- Vitest for unit tests
- Cypress for end-to-end tests
